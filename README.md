# 市场参数手册

一个可离线使用的中文金融市场参数手册。双击项目根目录的 `index.html` 即可打开，无需安装依赖或启动服务。词条中的参考资料链接需要联网访问。

## 使用

- 在页首选择股票、债券、基金、外汇、商品期货或数字资产。目录直接列出算式和单位，点开词条可查看定义、数字算例与资料来源。
- 输入中文名、英文名或缩写进行搜索。可在已选的市场内继续查找，例如在债券分类中搜索 `YTM`。按 `/` 聚焦搜索，按回车跳到结果。
- 在“一张债券的两种利率”中拖动市价，比较票面利率与当期收益率。手机上点标题即可展开。演算采用假设数值。

## 维护词条

`catalog.js` 管理市场、词条和资料来源。新增词条时，参照同组条目填写名称、中英文检索信息、定义、单位、公式、算例、读数提示和来源标识。市场列表、条目数量和搜索索引会随数据更新。

`index.html` 提供页面与词条模板，`app.js` 负责分类、搜索和债券算例，`styles.css` 管理桌面与手机布局。
